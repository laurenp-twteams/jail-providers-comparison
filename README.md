# Jail Commissary & Communications Provider — Report Comparison Tool

Compares two research passes on jail commissary and communications providers side by
side — Report A (the v6 report) vs. Report B (a second, independent pass) — so you can
quickly see where they agree, disagree, and which providers are worth a second look.

**Open it:** double-click `index.html` (no install needed), or use the live version:
https://laurenp-twteams.github.io/jail-providers-comparison/

**How to use it:**

- Switch between **Communications** and **Commissary**.
- Filter by tier, facility focus, or comparison status (ranked in both reports, only one
  report, or ranked differently).
- Search for a company by name, or click any row to see both reports' write-ups, sources,
  and comparison notes.
- A **"unranked (grp N)"** pill means Report A placed that company in its own unranked
  group rather than skipping it — different from a plain "unranked," which means the
  company isn't in that group at all.

Comparison notes are labeled **verified** (both reports agree), **corrected** (a report
revised its own earlier draft), or **unverified** (worth confirming directly) — based only
on what's in the two reports, no outside research.
